# 🔰Introduction<a name="introduction"></a>
<p>
  Morph is a project that aims to create a program that "morphs" any type of file to any other type of file. 
  
  The project is just starting, so it only has a few types of conversions, but I plan to add more over time. I'm a physics student, so I don't have much time during the week and will be working on this on weekends.
</p>

# 🌟 Features<a name="features"></a>

- Already implemented (v1.0.0-alpha):
  - Mass modification of file's names 
  - PDF ↔ PNG
  - OGG ↔ MP3
  - Explanation of every feature (help)
  - GUI 

- Plan to implement:
  - Update GUI
  - Music (lossy)
    - MP3 → WMA , AAC (m4a/apple)
    - WMA , AAC → MP3 
  - Music (lossless)
    - FLAC ↔ AIFF , WAV , ALAC (m4a/apple)
  - Music (Lossy ↔ Lossless)
    - FLAC ↔ MP3
  - Film
    - MP4 ↔ AVI , MOV , WMV , MKV , FLV , WEBM , MPEG
  - Image
    - PNG ↔ JPEG / JPG , GIF , BMP , TIFF / TIF , WebP , SVG , HEIF / HEIC

- Want to implement (if possible) :
  - Document
    - DOCX ↔ PDF , ODT , TXT
    - TXT ↔ MD , RTF , ODT
  - Spreadsheets
    - XLSX / XML ↔ CSV , ODS
    - CSV ↔ JSON
  - Presentations
    - PPTX ↔ PDF , ODP
  - Scientific / technical documents
    - LaTeX → PDF
    - BibTeX → RIS , XML
  - Structured data
    - JSON ↔ XML , YAML , CSV
